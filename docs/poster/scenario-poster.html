对视障用户来说，命令行不是门槛 —— 他们每天都在用终端。
复制一条命令、按回车，全程不需要鼠标、不需要看屏幕。
三 个 场 景
谁会在什么时候用它
1
视障用户，想独自完成一次点餐
时刻：下班回家路上，想给自己点一份，不想麻烦同事或家人代劳。
卡在哪 App 里的菜单是一张张图片，读屏软件念不出内容；不知道哪几家店还开着，也看不到哪些餐品自己能吃。
怎么用 用读屏模式跑一条命令，直接得到纯文本：先列出门店（营业状态 + 距离），再逐项念出餐品的能量、钠含量和能不能吃。
2
高血压 / 糖尿病患者，每天要控钠控糖
时刻：医生说要限钠，但麦当劳的菜单页面上根本不标营养成分。
卡在哪 凭名字和图片猜 unhealthy 或不健康。实测 15 款汉堡里只有 2 款钠含量低于 WHO 单餐参考值 —— 光看菜单选，选错的概率很高。
怎么用 选定「限钠」档位，它会按钠从低到高排，并明确念出每一项是否高于本餐参考值、超出多少毫克。只陈述数值关系，不给产品打分。
3
子女想替父母点一份
时刻：爸妈上了年纪，看不清手机小字，也记不清自己想吃什么。
卡在哪 把字号调大也没用 —— 一屏还是几十个选项，老人选不出来。反过来，替他们点又不知道哪些适合长辈的身体情况。
怎么用 大字模式一次只给 3 个选项，条目之间留空行，不出现表格和符号。你念一句，或直接把手机递过去，都行。
怎 么 体 验
三条命令，不用申请任何东西
1
先看效果 —— 不需要 Token，营养数据是官方 MCP 真实返回的快照
git clone https://github.com/Lion-bot2026/mcd-a11y-order.git
cd mcd-a11y-order
./scripts/mcd-a11y demo --mode screen-reader --profile sodium
只想试控糖或控能量档？加 --profile carb --meal-kcal 600 即可。
2
切成大字版看看 —— 一次 3 项、留白、无符号
./scripts/mcd-a11y demo --mode large-print --profile sodium
3
查你附近的真实门店 —— 这一步才需要 MCP Token
export MCD_MCP_TOKEN=你的Token
./scripts/mcd-a11y plan --keyword "望京" --profile sodium
Token 在 open.mcd.cn/mcp 申请。也可以先跑 ./scripts/mcd-a11y profiles 看四个档位的阈值出处。

它 不 做 什 么
把话说清楚，比说得漂亮重要
  • 不自动下单、不代付。下单必须手动加 --confirm 二次确认。
  • 不提供门店无障碍设施信息。麦当劳 MCP 不返回坡道、无障碍卫生间、低位柜台等数据，工具无法核实，请到店前致电门店确认。
  • 不量化特制后的钠含量。官方的特制接口不返回分项营养数据，所以只给方向性提示，不编造「去酱能减多少毫克」。
  • 不提供低蛋白档位。慢性肾脏病的蛋白质摄入需按体重与分期个体化确定，给固定克数会有误导风险。
  • 不是医疗或营养建议。只陈述「某个数值与某个参考值的高低关系」，不对产品本身作评价。
